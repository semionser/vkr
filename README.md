# Student Testing System — Flask + SQLite

## Исправленная версия

### Запуск в Windows

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python seed.py
set FLASK_DEBUG=1
python run.py
```

Открыть в браузере:

http://127.0.0.1:5000/

### Учётные записи

Администратор:
- login: `admin`
- password: `admin123`

Преподаватель:
- login: `teacher`
- password: `teacher123`

Студент регистрируется через `/auth/register`.

## Важно

Папки `templates` и `static` находятся внутри `app`, поэтому Flask корректно находит шаблоны и CSS.

## Безопасность

- **Секретный ключ** не хранится в коде: берётся из переменной `SECRET_KEY` (или файла `.env`), иначе создаётся автоматически в `instance/secret_key` (файл не попадает в git).
- **CSRF-защита**: каждая POST-форма содержит одноразовый токен сессии (`{{ csrf_input() }}`), запросы без него отклоняются с кодом 400.
- **Разграничение доступа**: разделы `/student`, `/teacher`, `/admin` закрыты по роли на уровне blueprint (`app/security.py`), чужая роль получает 403.
- **Защита от подбора пароля**: 5 неудачных входов за 5 минут для пары «логин + IP» блокируют вход.
- **Пароли** хранятся в виде хеша (Werkzeug), при регистрации — минимум 8 символов.
- **Cookie сессии**: `HttpOnly`, `SameSite=Lax`, `Secure` при `HTTPS=1`; сессия живёт 8 часов.
- **HTTP-заголовки**: `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`, HSTS при HTTPS.
- Режим отладки выключен по умолчанию (включается `FLASK_DEBUG=1`).

Демо-пароли из `seed.py` (`admin123` и т.п.) — только для локального запуска. На сервере смените их сразу после развёртывания.

## Новые возможности

- **Учебные группы.** Администратор создаёт группы и распределяет по ним студентов; студент может выбрать группу при регистрации. Преподаватель назначает тест одной или нескольким группам. Тест без групп доступен всем.
- **Защита от списывания.** Перемешивание вопросов и вариантов ответа, случайная выборка N вопросов из банка. Состав и порядок фиксируются в попытке и не меняются при обновлении страницы.
- **Частичные баллы.** Режим «Частичные баллы»: доля = (верно отмеченные − ошибочно отмеченные) / число правильных, в пределах от 0 до 1.
- **Разбор ошибок.** Возможные режимы: не показывать; только свои ответы; правильные ответы после последней попытки (по умолчанию); правильные ответы сразу.
- Ответы, отправленные позже чем через 30 секунд после окончания времени, не засчитываются.

Старая `database.db` обновляется автоматически при запуске: недостающие колонки добавляются (`app/schema.py`).
